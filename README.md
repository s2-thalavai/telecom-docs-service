# Telecom Docs Service

A Spring Boot 3.5 / Java 21 Telecom Customer API whose reference documentation is generated by
**Spring REST Docs**. Every example request and response, every field table and every error example comes
from a test, and the build fails if the documentation and the API drift apart.

| | |
|---|---|
| API | Plans (public), Customers v1 (CRUD, paging, status workflow), Customers v2 (restructured read) |
| Security | HTTP Basic, roles `AGENT` / `ADMIN`, RFC 9457 errors for 401/403 |
| Docs | Spring REST Docs (MockMvc) + Asciidoctor → HTML served at `/docs/index.html`, published to GitHub Pages |
| Guards | strict field docs, Asciidoctor `failIf WARN`, endpoint-coverage check, a test that the served HTML contains every section |
| Optional | `-Popenapi`: OpenAPI 3 from the same tests (restdocs-api-spec) + Swagger UI |
| Infra | Dockerfile, Docker Compose (MySQL + static docs host), Kubernetes, Makefile, GitHub Actions |

## Quick start

```bash
make docs            # docs tests -> snippets -> target/generated-docs/index.html
make open-docs       # same, then open in the browser
make run             # app on :8080, docs at http://localhost:8080/docs/index.html
make verify          # everything, including coverage and integration checks
make up && make smoke
```
